# Shipped

Every site the studio has made so far, reduced to what a visitor would remember. A new client's site should not share a hero idea, a type pairing or a palette with any line here, and should not lean on the same structural device (the same section as the spine of the page). Same category is not an excuse: two churches from one studio must look like two churches.

| Client · category | Type | Palette | Hero and spine |
|---|---|---|---|
| Christy Eller Design · design studio | Fraunces + Inter | cream, terracotta | split hero with a rounded 4:3 photo; three bordered cards; accent band |
| Grace Community Church · small neighbourhood church | Literata (opsz) + Hanken Grotesk | paper, brown-black ink, garden green, one tan band | the week as three display lines (Sunday / Wednesday / second Saturday); ruled schedule rows; dated notes; two plain quotes; "Come by" contact block |
| Blackline Climbing · bouldering gym | League Gothic + Schibsted Grotesk | chalk, real black, orange only for what is new, one coffee-brown band | three-line poster headline, third line in orange; the week as a seven-column board under a black rule; three-up feature row under black rules; big-date event rows |
| Front Range Tool Library · nonprofit lending library | Public Sans | navy, manila, dot-grid pegboard | pegboard hero with a manila tag; ruled columns; numbered 1-2-3 "how borrowing works"; closing accent band |
